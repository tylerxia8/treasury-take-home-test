How to use these sample labels

Screenshot each label below (your OS region-capture works well) and save it with the filename shown above it. Then drop the images into the app's Batch upload tab along with applications.csv from this folder. Expected outcomes:

  • old_tom_bourbon.png → Pass (everything matches)
  • harbor_mist_gin.png → Fail — the warning heading is "Government Warning:" in title case, not all caps
  • silver_birch_vodka.png → Needs review — the label shows 40% but the application says 35%
